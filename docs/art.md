# Regenerating the art

Most art is generated by scripts so you can restyle it. They need Python 3 and Pillow
(`pip install pillow`) and are run from the repo root:

```bash
python tools/art/generate_background.py assets/levels/level_01/background
python tools/art/make_level_backgrounds.py
python tools/art/generate_tiles.py assets/levels/common/tiles/kenney_industrial assets/levels/common/tiles/data_center
python tools/art/generate_machines.py assets/levels/common/machines/data_center
python tools/art/generate_projectiles.py
python tools/art/generate_pit_hazards.py
python tools/art/generate_icon.py icon.png
```

After regenerating, run `godot --headless --path . --import` so Godot re-imports the PNGs.

The pictures are cartoon emoji of Google's Noto Emoji set (Apache License 2.0) downloaded as published (128 px, the size they are shown at), put on a soft pastel square and saved as small palette PNGs (about 3 KB each, 135 KB in all). Brightness of the background layers is set at run time in
[scripts/level/background.gd](../scripts/level/background.gd) (`*_TINT` constants), not in the images.

The third-party art by Kenney (CC0) is the source for the hero's poses (`tools/art/sources/kenney_platformer_player/`, see `generate_player.py`), the
zombie's (`assets/characters/kenney_platformer/`) and the base tile sprites (`assets/levels/common/tiles/kenney_industrial/`);
`assets/levels/common/tiles/kenney_industrial/NAMES.md` maps the pack's numeric file names to the descriptive names
used here. Each folder keeps its `License.txt`.

## Asset layout

**All pictures and sounds live in `assets/`**, grouped as `assets/<category>/<feature>/...` (and, for art that comes in styles,
`<category>/<feature>/<style>/<group>/<file>.png`). Nothing else holds art: `levels/` is level *data* (JSON), `scripts/` is code,
`scenes/` is scenes (`python tools/audit_assets.py` fails on a picture or sound in any of them). `levels/` and `assets/levels/` have the
same shape: the data of a level is `levels/<id>/`, its art `assets/levels/<id>/`. File names are never changed by the layout, so a
sprite's name is enough to find it, and `SpriteLibrary` and `AssetPaths` are the only code that knows the folders.

```
assets/
  levels/                          the levels' art (their data is in levels/, same shape)
   common/                         art shared by every level
    tiles/                         level tiles and props
      kenney_industrial/           the original Kenney set (CC0); NAMES.md maps its old numeric ids
        terrain/ structure/ equipment/ hazards/ lights/ signage/
      data_center/                 our themed replacements, same names and same category folders
        terrain/ structure/ equipment/ hazards/ lights/ signage/
    machines/
      data_center/                 generated machines (style)
        gpu_rack/ supercomputer/ monitoring_station/ server_tower/    image + _leds_a/_leds_b + _shadow
        parts/                     shared moving parts (the fan blades)
    pit_hazards/                   the deadly-pit liquids, the robot piranha and the other pit creatures
   level_01/ ... level_06/
    background/                    that level's five parallax layers
  characters/
    saboteur/player/               the hero: our own art made from Kenney's (generate_player.py), 17 poses, each in parts: <part>/<style>/<character>_<pose>_<part>.png
    kenney_platformer/zombie/      Kenney's zombie (the AI Bro), ten poses (see tools/audit_rules.json)
  projectiles/pixel_art/           the throwable objects (cats/ everyday/ paintings/)
  powerups/box/                    the power-up box and its break frames
  vehicles/mech/                   the mech's parts, damage layers, missile and flames
  bosses/saltman/                  RAM Saltman's layers; spray/ holds what he shoots
  effects/                         generic effects any feature can use: explosion, smoke, fire, sparks, glows
  ui/                              icons/ (the puzzle window), captcha/ (the captcha minigame's pictures, riddles and credits)
  audio/music/                     the music (credits in audio/CREDITS.md)
levels/                            level data only (no pictures): level_0N/level.sablevel.json and common/tile_registry.json
```

How a name becomes a folder:

- **Tiles:** the first word of the name picks the category, for example `ground_start` -> terrain,
  `siren_blue` -> lights. The word-to-category table is `SpriteLibrary.TILE_CATEGORIES`.
- **Machines:** the machine is the name without the `machine_` prefix and without
  `_leds_a`, `_leds_b` or `_shadow`: `machine_gpu_rack_shadow` -> `gpu_rack/`.
- **Themed over original:** `SpriteLibrary.tile()` uses the sprite from `tiles/data_center/` when one
  exists with the requested name, and falls back to `tiles/kenney_industrial/` otherwise.

To add art: put the file in the right folder with the right name (a new kind of tile also needs its
first word added to `TILE_CATEGORIES`). `tools/tests/assets_test.gd` checks that every file is
where the rules say and that everything loads, so a misplaced file fails `tools/run_tests.sh`.
Godot creates the `.import` file next to each image the first time you import.
